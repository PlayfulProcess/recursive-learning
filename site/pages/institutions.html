Institutions

Organisations working on alignment, AI safety and humane technology, by quite different routes: technical research, testing and evaluation, governance and policy, public-interest research, public communication and more. Each card describes the organisation from its own site and links out to it.

Listing is not endorsement, and nothing here is ranked: the groups follow the kind of work, and names inside a group are in alphabetical order. The list is not complete: suggest an addition or a correction (opens GitHub in a new tab).

How this list is made. Each description is paraphrased from the organisation’s own pages as they read on the day they were checked (shown on the card when the data records it); where a site says little, the card says little. Groups are a rough sorting by approach, and many organisations work across several. The cards are built from research/institutions/institutions.json in the public repo (opens GitHub in a new tab): an issue, or a pull request against that file, is how to add one, fix a description or question a grouping.
