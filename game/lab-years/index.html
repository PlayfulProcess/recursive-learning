The Lab Years

A 90-minute pass-and-play strategy game about the AI race. 3-5 players, one device. Each of you is an AI-lab researcher with a public role and a secret objective; a hidden World decides how the race actually resolves, and none of you finds out which one until it does. Full rulebook.

Quick rules

A round is one year. Compute +1 for everyone, an event card (or more, as the race rises) is drawn, then each player takes a full turn of 3 actions: Research (draw a card), Build (spend compute + a card: capability +1, your company value +1), Release (a bigger step: capability +2, race +1 — others may respond with an Audit or a Whistleblow before it resolves), Secure (bank matching cards toward one of the 4 safeguards), Publish (a card face up, helping everyone next year), Lobby (a small push toward international agreement), Trade, or a role's own power.

From 2027, RSI ("recursive self-improvement") cards are shuffled into the event deck. One only fires if capability has crossed the threshold; below it, it fizzles and says why. When it fires, it resolves through the same belief tree the film uses: alignment secured? containment secured? Proceed is the best ending; Regulate and Contain let the game continue under new limits; if neither safeguard held, it's catastrophe — everyone loses, whatever their secret objective was.

Two World cards were dealt face down at the very start and nobody has seen them: which Takeoff theory is true (how RSI actually behaves) and which Alignment dynamics theory is true (how the alignment safeguard actually holds up). Clue cards drop hints along the way, never certainties. You may spend up to 3 belief tokens, in secret, betting on which theories are true — correct guesses add to your score when the World is finally revealed.

Assumptions this game states outright: if capability crosses a threshold and neither safeguard has been secured, this game's tree calls that catastrophe. If it has, the game calls that the best ending. Both are this game's rule, not a forecast — see rules.html for the rest, and the credits for every mechanic borrowed from elsewhere.

Set up the table

The start year is cast with The Fork's own coin-draw, over 2017-2026. The later it lands, the more capability, compute and safeguard progress is already on the board from real, dated history (each with its source) — face up before anyone's first turn.

    Scoring

    How the odds were set: scripts/sim-lab-years.mjs plays ~2,000 games with simple bots. A mixed table lands on catastrophe about 9-15% of the time (higher within any single World, since 3 of the 4 alignment-dynamics theories can push it as high as 25-41%; Plateau worlds never resolve RSI at all, so the whole table's timeout share is higher than a single-World table's would be). No secret objective wins more than about 40% of the games it was dealt into. See the PR for the full table, by World combination.
